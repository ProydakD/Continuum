Источник: пользовательское задание «Continuum — E-007: Emergent Shared Protocol».
Полная копия и SHA-256 находятся вне Git в artifacts/e007-001. Этот список
не заменяет задание и не сокращает его; PASS возможен только по фактическим данным.

Дополнительная важная граница: одинаковые лимиты применения не означают одинаковые
затраты разработки. Их нужно явно разделять; H2 без H5 не доказывает экономической
выгоды совместного протокола. Ни одна успешная запись не доказывает эмерджентности.
