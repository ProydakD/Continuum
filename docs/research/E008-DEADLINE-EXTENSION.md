# E008-A007: разрешённое продление срока на 72 часа

23 октября 2026 серия `batch-015` остановилась с кодом 1: `registered series
deadline`. Сохранены 2858 исходов: 2454 завершённых, 51 отказ по бюджету,
159 ошибок и 194 пропуска по зависимостям. Все 568 следующих позиций
не начаты; первая — `j02859`. Основной D960 полностью проверен; из 576
robustness выполнены первые восемь (семь завершённых, один отказ).

Последний `j02858` сохранил ошибку чтения `TimeoutError`. Его завершение
зарегистрировано на 0,3394108 секунды позже исходного срока; это сохранённый
хвост остановки, а не успешное выполнение в пределах 72 часов. Контроллер
остановился во время ожидания первого восстановления: `1-started.json`
уже существует, но отправки GET не было. Наблюдаемая причина остановки —
локальный временной предел, не доказанный rate limit шлюза.

Пользователь отдельно разрешил: «Да, продлить на 72 часа и продолжить
без повторов». А007 добавляет ровно 259200 секунд к прежнему абсолютному
сроку, не к моменту перезапуска. Начало `1792487989.4194686` и исходный
предел `1792747189.4194686` сохраняются; новый предел —
`1793006389.4194686`, 26 октября 2026, 13:19:49 по Самаре.

Исходная регистрация, строка политики в журнале расходов, все модели,
порядок контекстов, протоколы, размеры памяти и остальные ограничения
не меняются. Дополнительное время применяется только через отдельные
зафиксированные А007 и её допуск. Без А007 старый временной предел
по-прежнему останавливает запуск. STOP, лимиты запросов, запрет неизвестных
сетевых исходов и защита от обратного хода часов сохраняются.

Первый неотправленный слот восстановления `j02858` продолжается без
перезаписи времени его начала; допускаются только исходные три GET,
не дополнительные Responses. Будущие HTTP 502 сохраняют прежнюю политику
из десяти проверок раз в минуту. Новый HTTP 408 по-прежнему останавливает
серию. Успешные прежние проверки доступности и cold REF не повторяются.

А006-R1 проверяется как исторический допуск по своему коммиту. Все старые
привязки исходов сохраняются; только позиции от `j02859` получают коммит
и хеш А007. Итоговый аудит отдельно показывает исходный срок, разрешённое
продление и сохранённое превышение последнего timeout, не меняя прошлое.

До допуска: 347 тестов E008 прошли, включая 26 тестов продления; локальный
контроллер проверен без API. История 2858 позиций проверена с запрещёнными
сетевыми вызовами и новыми записями, включая 119 сохранённых восстановлений.
Проверка остановки подтвердила неизменность 47594 файлов. Проверки А007
не являются свидетельством научной эффективности. После оставшихся 568
позиций необходим полный анализ H1–H6, ресурсов, provenance и пар миров.
