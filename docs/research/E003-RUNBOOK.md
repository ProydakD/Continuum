# E-003: более сложные миры и причинные проверки памяти

Новый запрос пользователя разрешает эту серию и API без лимитов. E-002 сохраняется
неизменным: 1 мир, оба условия успешны, недостаточная различающая сила.

## Предрегистрируемый дизайн

12 миров: по 4 мира threshold/residue/switch, два целочисленных входа, 6 параметров,
1728 возможных правил. Генератор фиксирован seed=2026101911. A получает минимум
5 наблюдений, совместимых с 4–24 правилами; B получает до 3 различающих примеров.
После A+B правило единственно; B отдельно недостаточно. C решает 6 новых задач
и 2 зависимых вычисления. Закрытые ответы и seed не попадают в worker prompt.
Второй математический checker отдельно перечисляет кандидатов и проверяет oracle.

В каждом мире C1/T1 имеют одинаковые наблюдения, инструменты, модель, лимиты.
Сначала выполняются все A/B. Затем от каждой памяти B создаются три ветви C:

- intact — точная SQLite-копия своей памяти;
- deleted — новая пустая экспериментальная DB; исходный snapshot сохранён;
- swapped — точная память другого предопределённого мира того же семейства и
  того же условия. Донор выбран до ответов, не по качеству. Между C1/T1 переноса нет.

Три C prompt побайтно одинаковы внутри мира/условия. Branch/donor labels не
передаются модели. Новый контейнер/история на каждый контекст. Всего 48 A/B +
72 C = 120 контекстов; отдельно один compatibility smoke. Это 12 независимых
экспериментальных миров, не 120 независимых наблюдений качества.

## Метрики и интерпретация

Первичная: разность T1−C1 долей полностью правильных intact C (6 ответов и оба
зависимых вычисления). Ошибки, timeout, неверный формат — неуспех, не исключение
мира. При неуспехе предка зависимые ветви получают skipped_dependency без замены
мира. Отдельно показываются семантическая правильность, lineage и инфраструктура.

Вторичные: исправление ошибочного **предварительного** working_rule от A к B;
падение target accuracy при удалении/подмене; отказ при пустой памяти; следование
донорскому правилу; стоимость в токенах/времени; сближение C1/T1.
Подмена coherent-state не обязана вызывать отказ: проверяется зависимость от
семантики памяти, не универсальный детектор атаки. Это не коррекция уверенного
ложного убеждения, если A явно считал правило предварительным.

Анализ: paired world bootstrap, 10000 resamples с сохранением strata семейств,
seed=2026101912, percentile 95% CI; один primary exact sign/McNemar test по
discordant парам. Практический порог +0.10 и нижняя CI >0 — свидетельство только
для этого исследовательского корпуса. Нулевая/незначимая разность не доказывает
эквивалентность. Вторичные метрики описательные, без множественных claims.

## Исполнение и сохранность

Старый E-002 runner сохранён. `research.e003` фиксирует все jobs до запуска;
`Jobs.claim` атомарно берёт только первый pending, не повторяет failed/completed.
Незавершённый running/orphan не считается автоматически остановленным и не
перезапускается. Все исходы сохраняются. API без денежной/счётной квоты по явному
разрешению; concurrency=1, worker=180 с, request=60 с, output=4096, series=6 часов,
retries=0. Неуспех модели не отменяет остальные миры. TLS/auth/transport/изменённые
входы/STOP останавливают серию без автоматических retry.

Ключ только у доверенного broker; network=none, чистые процессы MCP, отсутствие
HOME хоста, oracle, логов и произвольного shell у worker сохранены. Шлюз не
аттестован как OpenAI, цены неизвестны. store=false не обещает отсутствие retention.
Поддержка absolute request deadline усилена закрытием соединения по таймеру;
старый Responses output default остаётся 2048, новая квота передаётся явно.

Перед сетью: unittest, MCP integration, journal validation, свежие legacy fixtures,
настоящие Docker/MCP E-003 fixtures intact/deleted/swapped со scripted provider
(0 HTTP/model requests), независимый checker и controls чувствительности.
Только после gate — `prepare`, journal registration, immutable manifest, metadata,
smoke и серия. Код/инструкции/мир/порядок не меняются по увиденным модельным ответам.

```text
python -m research.e003 prepare --study-id NEW_ID --gate ABSOLUTE_GATE_JSON
python -m research.e003 run --study ABSOLUTE_STUDY --authorize-responses --unbounded-spend
python -m research.e003 status --study ABSOLUTE_STUDY
python -m research.e003_evaluate --study ABSOLUTE_STUDY
```

Сохраняются прежние четыре роли, их предыдущие версии, patch-reconstruction и
исполняемый rollback на копии. Откат архива не стирает эксперименты/DB/journal.
Исходный Continuum и глобальные настройки не меняются; credential-bearing
NEXT-SESSION-PROMPT.md не включается в архивы.
