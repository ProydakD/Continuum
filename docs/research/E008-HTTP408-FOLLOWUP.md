# E008-A006: отдельное возобновление после HTTP 408

Пользователь явно разрешил продолжение с `j02698`, без повторения 2697
завершённых позиций. Исход `j02697` сохраняется как ошибка провайдера:
в запечатанном контексте наблюдались POST 200, затем POST 408. Это не
доказательство ограничения частоты запросов.

Поправка действует только для этой сохранённой ошибки. Модели, исходные
часы, лимиты, выбранные протоколы и все прежние поправки остаются неизменными.
Сначала выполняется отдельная ограниченная проверка доступности той же
модели: до трёх GET с исходными задержками 30, 120 и 300 секунд. Новых
Responses-проб нет; расходы GET учитываются в исходном журнале.

Для будущих HTTP 502 сохраняются десять проверок с интервалом в минуту.
Новые HTTP 408 и другие фатальные классификации не получают автоматического
исключения. Отсутствие модели в каталоге не является доказательством
недоступности Responses; при остановке сохраняется фактическая причина.

А005 проверяется по своему допущенному коммиту, а А006 — по отдельному
коммиту и точным хешам исходников. Родительский аудит ограничен прежними
позициями, чтобы не смешивать привязки новых контекстов с А005. Допуск А006
возможен только при отсутствии уже начатых позиций 2698–3426.

Перед сетевым запуском обязательны проверки неизменности исходов,
отсутствия повторов, области изменения, тесты и автономная проверка
контроллера. Их фактические результаты закрепляются в отдельном offline gate.
Продолжение не меняет научный дизайн и не является итогом исследования.
